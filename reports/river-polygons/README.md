## 实验发现和最终策略

单纯扫描固定格子时，灰色厚侧面可能伸进下一个空格，被模型当作白板。提高固定亮度门槛又会漏掉较暗牌面。最终保留原有牌体/空位检测、牌位唯一性、完整性和箭头处理，固定四角负责普通牌的分类裁切；没有仅凭“这个坐标可能有牌”向模型虚构一张牌。

立直横牌及其后的偏移继续由独立牌体几何处理，横牌直接沿用原识别。普通牌还要求标定多边形至少 85% 落在观测牌体内、四边都有白色支持；位置或画面变化时回到原识别。

另一处实际反例：`3803049411.jpg` 对家牌河 `[0,3]`，原图和辅助数字为二万；固定裁切曾给三万约 64%，原流程能认对。因此新增固定裁切须达到主门槛（默认 90%）才直接采用；否则回到原流程。原流程仍保留用户配置的“首选 >50%、至少为第二名 3 倍”补充规则及既有横牌字形校验。回退使用原流程完全相同的原生像素裁切，避免一像素的边界差异改变临界读数。

原试验中还纠正过普通五筒被误当横牌的情况，但收紧新增路径后，该具体裁切回退到原流程；最终版本没有以这个变化作为验收成绩，也没有声称已解决所有立直判断问题。
