# 副露透视识别：数据驱动修复（draft-23）

已联网检索并选取完整雀魂截图，建立 47 个真实局部案例：32 张去重原图、21 个来源家族、46 组副露和 10 个反例，覆盖四个座位。单牌来源为 [pjura](https://huggingface.co/datasets/pjura/mahjong_souls_tiles) 与 [cvmaj](https://github.com/xdedss/cvmaj)，完整场景来自本地已留存的公开截图及用户帧；本次没有重新训练主网络。细节见 [数据集说明](../../data/meld-orientation/README.md)及 [联网检索记录](research.json)。

修复：三张副露和杠牌统一角点的画面坐标顺序；旧模板轮廓缺失时使用现有网络几何，完整来源矛盾时不确认；白板不依赖字形角度；行几何允许透视倾斜并保留直线残差和相邻牌体约束。相邻多组副露可以由强候选确定唯一边界，但牌种确认沿用原规则，不能因此把两个未知牌都补成已确认。

真实固定集正确组数 **28→32 / 46**，完整区域 **24→26 / 37**，错误确认 **0**；10 个反例均未误认。受控几何变体 **412→672 / 672**，不是独立真实图片或主网络准确率。此前 69 组已确认副露的存档证据无变化。

完整回归 **598 项通过**，失败/错误/跳过均为 0。Tk 测试在本机显式指定现有 Tcl/Tk 目录，并在加载大量 GPU 会话前初始化；未修改用户的 Python 安装。建议工作流回放约 2.43–2.74 秒，另一个未确认响应约 1.87 秒，含 0.3 秒等待和界面轮询预留，不含真实窗口采集及首次预热。九张首次处理本次中位数约 1.54 秒，机器负载有波动；原九张图的局面、动作和 Q 分数保持一致。

**尚有 14 组未确认**：低分辨率字形、辅助文字牌面、特殊红/绿牌背或额外前景仍会阻止完整建议。未把未知算成功，也不声称所有场景已彻底解决。完整成功、失败及原像素见 [可筛选对照](index.html)。
