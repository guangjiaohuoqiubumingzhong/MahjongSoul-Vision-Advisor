# 右家吃牌方向修复（draft-22）

用户截图显示“请核对 meld_right：识别不完整”。对应原帧的四万、赤五万、六万已经识别正确，失败在吃牌朝向与来源确认：横放赤五万受侧视透视影响，牌体外框仍是竖长形，旧的外框宽高判断无法确定横牌。

现在复用三个白色正面的拟合角点。角点先恢复到画面轴顺序，避免模板的字形旋转改变边长含义，再比较对边平均长度。必须是同一行、两个直立牌面比例接近（最多相差 1.25 倍）、第三个比例至少达到前两者最大值的 1.5 倍。样例三个比例约为 0.752、0.418、0.404，横牌相对分离度约 1.80。明确相反的模板朝向不覆盖；来源仍由区域的吃/碰映射确认，牌种、赤牌阈值及网络推理保持原样。缺失、冲突及错误来源仍不确认。
