# 固定多边形回归真值

`manifest.json` 引用现有截图，不复制或修改原图。三张原始客户区图共 75 张牌河牌：倒计时 282 帧四家共 50 张；已有立直牌河 16 张；已有红中碰牌/箭头帧上家牌河 9 张。后两组沿用此前已核对真值，第一组在原生裁切放大图中逐张核对。

`public-review.json` 为对照中变化的五个公开牌位的人工像素复核，记录原图 SHA256、区域、牌位、框及标签；包括原有模型的两张错误（六万读七万、四索读七索），未改标签消除错误。该清单是根据输出变化挑出的开发回归，不算独立盲测。既有公开 15 张牌河标注仍读取 `data/public-mahjong/manual-regressions.json`。

这些真值仅用于评分，没有参与角点拟合、空位检测或运行时分类。标定仅来自 train 图像。
